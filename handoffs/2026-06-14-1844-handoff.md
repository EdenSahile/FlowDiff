## Blocages / échecs

### 1. `vercel dev` instable
Trois tentatives différentes (port 3000, 3001, 3333) — page blanche ou connexion qui tournait dans le vide. Cause : conflit entre `outputDirectory: dist` (build prod) et le dev server Vite sur un port dynamique. Solution retenue : deux serveurs indépendants (Vite + local-api-server).

### 2. Variables `.env` non chargées dans le serveur local
`process.loadEnvFile` absent sur la version Node installée, fallback manuel ne se déclenchait pas. Solution : `npx tsx --env-file=.env` (flag natif Node qui charge le .env avant exécution).

### 3. Package Python `pinecone-client` déprécié
`pip install pinecone-client` installe un package qui lève une exception. Solution : `pip uninstall pinecone-client && pip install pinecone`.

### 4. Classificateur trop restrictif
"Quelle est votre adresse ?" → classifié `static` au lieu de `rag`. Solution : `rag` devient le type par défaut (tout sauf livres/commandes).

### 5. tsx --watch ne détectait pas les changements de `api/aidenia.ts`
Cause : import dynamique (`await import(...)`) non suivi par tsx watch. Solution : import statique en haut de `local-api-server.ts`.
